# TypoTest - Typing Speed & Accuracy Trainer

A clean, modern typing trainer testing speed and accuracy across configurable time durations with detailed keystroke error analytics.

## Features

- **Timed typing challenges**: Timed typing challenges: 15 seconds, 30 seconds, and 60 seconds options
- Real-time performance feedback highlighting correct letters (green), errors (red), and current active cursor
- Live WPM (Words Per Minute), Accuracy percentage, and Keystroke counts
- **Detailed post-test analytics**: Detailed post-test analytics: raw WPM, net WPM, accuracy breakdown, and error character breakdown
- Instant test restart via keyboard shortcut or restart button
- History tracker saving high scores and past test performances in LocalStorage

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Typo-Test.git
   cd Typo-Test
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `typotest_typing_speed_accuracy_trainer.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/typotest_typing_speed_accuracy_trainer.html](http://localhost:8000/typotest_typing_speed_accuracy_trainer.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for TypoTest - Typing Speed & Accuracy Trainer.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
